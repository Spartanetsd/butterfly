# Крылья на рассвете

Маленька інтерактивна казка для дитини: дівчинка відкриває кокон, допомагає бабочці вперше полетіти й збирає пилок, щоб розбудити квітучий луг. Усі написи в грі російською.

Грати: https://spartanetsd.github.io/butterfly/

## Як грати

Три етапи — три різні ігри, без таймера, штрафів і програшу:

1. **Рожеві квіти** — торкнись квітки, бабочка прилетить і забере зернятко пилку.
2. **Сонні бузкові бутони** — над ними місяць. Треба трохи посидіти на бутоні: кільце наповнюється, бутон прокидається й віддає пилок.
3. **Золотий вітер** — порив вітру здуває пилок-пушинки. Їх треба ловити в повітрі.

Луг оживає з кожним зернятком: сонце піднімається, після першого етапу прилітають бджілки, після другого з'являється веселка. У траві ховаються четверо друзів (сонечко, равлик, їжачок, зайчик). Щоб розбудити друга, підлети й зупинись поруч. У фіналі видно, скількох друзів знайдено. Якщо торкнутися самої бабочки, вона робить сальто.

## Як викласти з iPhone

1. Розпакуйте архів у «Файлах»: з'явиться папка з 8 файлами.
2. На github.com/Spartanetsd/butterfly натисніть **Add file → Upload files**, виділіть усі 8 файлів (не папку) і натисніть **Commit changes**.
3. **Settings → Pages**: Source — **Deploy from a branch**, гілка **main**, папка **/ (root)**, **Save**. Через 1–2 хвилини гра відкриється за посиланням вище.

Щоб гра була як окремий застосунок: Safari → «Поділитися» → «На початковий екран».

## Як оновлювати

Замініть index.html на GitHub. Щоб офлайн-копія на телефонах точно оновилась, у sw.js змініть версію в рядку `const CACHE = 'krylia-v2';` (наприклад, на `krylia-v3`).

## Керування

- Телефон: торкніться квітки — бабочка полетить; ведіть пальцем — вона летить слідом.
- Комп'ютер: миша, стрілки або WASD (працює й у російській розкладці).
- Звук вимкнений, поки не натиснути кнопку в правому верхньому куті.
